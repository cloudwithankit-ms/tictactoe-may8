# Tic Tac Toe

A minimal tic tac toe game built with HTML, CSS, and JavaScript.

## Features
- Two-player game (X and O)
- Win detection
- Draw detection
- Reset button to start a new game
- Responsive design with gradient background

## How to Play
1. Open `index.html` in your browser
2. Player X goes first, then Player O
3. Click on any empty cell to make a move
4. First player to get 3 in a row wins
5. Click "Reset Game" to play again

- `index.html` - Game board and UI
